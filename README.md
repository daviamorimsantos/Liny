# Matriz Energética Brasileira — apresentação de Liny e grupo

Site independente para apresentação escolar em Biologia (Ensino Médio).

## Como abrir
- Abra `index.html` em um navegador moderno.
- Use a navegação superior, os botões de seta ou as teclas ↑/↓ para avançar pelas seções.
- Use **Salvar PDF** para imprimir ou exportar para PDF pelo navegador.

## Conteúdo
Conceitos de matriz energética e matriz elétrica; fontes renováveis e não renováveis; impactos ambientais; transição energética; conclusão e referências.

## Observação sobre dados
Os percentuais de 2024 seguem a EPE: 50% de renovabilidade na matriz energética e 88,2% na matriz elétrica, conforme o Balanço Energético Nacional 2025. A fonte oficial está referenciada no próprio site.
